# Приём заявок с сайта → Telegram

GitHub Pages отдаёт только готовые страницы и не умеет принимать формы. Поэтому формы на сайте
отправляют заявку на небольшую функцию в Cloudflare (бесплатного тарифа хватает), а она пересылает
её вам в Telegram. Пока адрес функции не вписан в `config.js`, формы честно говорят посетителю
«позвоните нам» и ничего не отправляют.

## 1. Создайте отдельного бота для заявок

В @BotFather: `/newbot` → получите токен. Используйте **нового** бота, не `@superskupkabot`:
токен лежит в настройках Cloudflare, и его утечка не должна затронуть бота по скупке аккаунтов.

## 2. Узнайте id чата

Напишите новому боту любое сообщение, затем откройте в браузере
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":число}`. Это `CHAT_ID`.
(Для группы: добавьте бота в группу, напишите сообщение, id будет отрицательным.)

## 3. Создайте Worker

1. cloudflare.com → Workers & Pages → Create → Worker → дайте имя, например `alterbeltech-forms`.
2. Edit code → замените содержимое файлом `form-to-telegram.js` → Deploy.
3. Settings → Variables and Secrets:
   - `BOT_TOKEN` — тип **Secret**, токен из шага 1;
   - `CHAT_ID` — id из шага 2;
   - `ALLOWED_ORIGIN` — адрес сайта без слэша на конце, например `https://имя.github.io`
     (если сайт на своём домене — он; можно несколько через запятую).

## 4. Подключите к сайту

В `config.js` впишите адрес Worker:

```js
formEndpoint: "https://alterbeltech-forms.ВАШ-АККАУНТ.workers.dev",
```

Загрузите файл на GitHub и проверьте любую форму: сообщение должно прийти в Telegram.

## Защита от спама

Уже есть: скрытое поле-ловушка, проверка адреса сайта (Origin), лимиты длины, проверка телефона.
Origin подделывается не из браузера, поэтому при спаме добавьте в Cloudflare правило ограничения
частоты (Security → WAF → Rate limiting rules) для адреса Worker.

Если в политике конфиденциальности (`privacy.html`) указан Telegram как канал получения заявок,
а вы выберете другой способ, поправьте раздел 5.
